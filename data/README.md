# Diabetes Dataset

This folder contains the dataset used for the Diabetes Prediction project.

## Dataset

- File Name: diabetes.csv

## Features

- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

## Target Variable

Outcome

- 0 = No Diabetes
- 1 = Diabetes

## Source

Pima Indians Diabetes Dataset (Kaggle)
